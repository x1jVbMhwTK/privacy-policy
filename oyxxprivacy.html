本隐私政策适用于欧创易 App 向用户提供的英语学习、学习计划、学习提醒、复习提醒、语音播放、在线语音合成等相关服务。

本应用当前主要为英语学习工具类应用，当前不提供以下功能：

  • 不提供账号注册功能；
  • 不提供账号登录功能；
  • 不提供支付功能；
  • 不提供订单交易功能；
  • 不提供商品展示或商品购买功能；
  • 不提供社交发布、评论、私信等功能；
  • 不主动收集通讯录、短信、通话记录、精确位置信息、身份证号、银行卡号、人脸信息等敏感个人信息。

二、我们如何收集和使用您的信息

我们遵循合法、正当、必要和诚信原则，仅为实现产品功能所必需的目的收集和使用相关信息。

本应用主要处理以下几类信息：

1. 英语学习内容和学习记录

当您使用本应用进行英语学习时，可能会在本地生成或保存以下信息：

  • 您添加、编辑或保存的单词、句子、文本内容；
  • 学习计划；
  • 学习提醒时间；
  • 复习提醒时间；
  • 学习进度；
  • 收藏内容；
  • 本地学习记录；
  • 应用设置项，例如提醒开关、震动开关、语音播放偏好等。

使用目的：

  • 为您提供英语学习功能；
  • 保存您的学习内容和学习进度；
  • 提供学习计划和复习提醒；
  • 提供个性化的本地学习体验；
  • 在您下次打开应用时继续展示相关学习内容。

收集和使用方式：

  • 由您主动输入、添加、编辑或设置；
  • 由应用根据您的使用操作在设备本地生成；
  • 默认保存在您的设备本地数据库或本地存储中。

保存范围：

上述信息主要保存在您的设备本地。除非您主动使用需要联网的功能，例如在线语音合成，否则我们不会主动将您的学习内容上传至服务器。

2. 在线语音合成/TTS 功能

本应用可能提供在线语音合成、在线朗读或在线 TTS 功能，用于帮助您进行英语听读学习。

当您主动使用在线语音合成功能时，本应用可能需要通过网络请求语音合成服务接口，涉及以下信息：

  • 您选择或输入的待朗读文本；
  • 语音合成参数，例如语速、音量、音色等；
  • 网络请求时间；
  • 网络连接状态；
  • 应用版本信息；
  • 必要的设备基础信息，例如设备型号、操作系统版本等，具体以接口服务正常运行所需为限。

使用目的：

  • 将英语文本转换为语音；
  • 为您提供朗读、听力练习、跟读学习等功能；
  • 判断在线语音功能是否可用；
  • 排查在线语音播放异常或网络请求异常。

收集和使用方式：

  • 仅在您主动使用在线语音合成功能时，通过网络请求发送；
  • 语音合成服务返回语音结果后，由本应用播放或缓存必要的播放数据。

特别说明：

我们不会将您的待朗读文本用于与语音合成无关的目的。若您不希望文本通过网络发送，您可以不使用在线语音合成功能，或关闭网络连接后使用本应用的其他本地功能。

如本应用使用第三方在线语音合成服务，我们将在本政策“第三方 SDK 或第三方服务说明”部分中列明相关信息。

3. 通知和学习提醒信息

为了帮助您坚持英语学习，本应用可能提供学习提醒、复习提醒、计划提醒等功能。

当您开启相关功能时，本应用可能会使用以下信息：

  • 学习提醒时间；
  • 复习提醒时间；
  • 学习计划内容；
  • 提醒标题；
  • 提醒频率；
  • 是否开启震动提醒；
  • 是否开启通知提醒。

使用目的：

  • 按您设置的时间提醒您学习英语；
  • 提醒您进行单词复习、句子练习、听读训练等；
  • 提高学习计划执行效果；
  • 帮助您养成持续学习习惯。

收集和使用方式：

  • 由您主动设置；
  • 保存在设备本地；
  • 到达提醒时间后，通过系统通知、震动等方式提醒您。

4. 设备和应用运行信息

为了保障本应用正常运行、排查异常问题、提升应用稳定性，本应用在运行过程中可能会使用或生成以下信息：

  • 应用版本号；
  • 设备型号；
  • 操作系统版本；
  • 网络连接状态；
  • 应用崩溃信息；
  • 应用运行异常日志；
  • 功能调用状态。

使用目的：

  • 保障应用正常运行；
  • 判断在线功能是否可用；
  • 排查应用崩溃、卡顿、语音播放失败等问题；
  • 提升应用兼容性和稳定性。

收集和使用方式：

  • 应用运行过程中由系统或应用自动生成；
  • 默认用于本地运行判断和问题排查；
  • 如未接入第三方统计或崩溃分析 SDK，则不会主动上传至第三方统计平台。

5. 网络状态信息

本应用可能读取设备网络连接状态。

可能涉及的信息包括：

  • 当前是否联网；
  • 当前网络类型，例如 Wi-Fi 或移动网络。

使用目的：

  • 判断在线语音合成功能是否可用；
  • 在网络不可用时向您提示；
  • 避免因网络不可用导致语音合成失败；

收集和使用方式：

三、应用权限使用说明

为了实现英语学习、学习提醒、语音播放等功能，本应用可能申请或使用以下系统权限。我们仅会在实现对应功能所必需时使用，不会用于与功能无关的目的。

1. 通知权限 POST_NOTIFICATIONS

使用目的：用于向您发送英语学习提醒、复习提醒、学习计划提醒等通知。

是否可关闭：可在系统设置中关闭。

2. 震动权限 VIBRATE

使用目的：用于在学习提醒、复习提醒触发时提供震动提示，增强提醒效果。

是否可关闭：可在应用设置或系统设置中关闭。

3. 精确闹钟权限 SCHEDULE_EXACT_ALARM

使用目的：用于按照您设置的时间准确触发学习提醒、复习提醒、定时学习任务。

是否可关闭：可在系统设置中管理。

4. 开机广播权限 RECEIVE_BOOT_COMPLETED

使用目的：用于设备重启后恢复您已设置的学习提醒或复习提醒。

是否可关闭：可通过系统限制应用自启动等方式管理。

5. 唤醒锁权限 WAKE_LOCK

使用目的：用于在提醒触发或语音播放等必要场景下短暂保持设备唤醒，确保提醒或播放正常执行。

是否可关闭：系统自动管理。

6. 网络访问权限 INTERNET

使用目的：用于在线语音合成、访问隐私政策页面等需要联网的功能。

是否可关闭：关闭网络后相关在线功能不可用。

7. 网络状态权限 ACCESS_NETWORK_STATE

使用目的：用于判断当前网络是否可用，以便提示在线语音功能状态。

是否可关闭：系统自动管理。

您可以通过以下路径管理应用权限：

Android 系统设置 → 应用管理 → 欧创易 → 权限管理

关闭某些权限后，可能会导致对应功能无法正常使用。例如：

  • 关闭通知权限后，您可能无法收到学习提醒；
  • 关闭精确闹钟权限后，提醒时间可能不够准确；
  • 关闭网络连接后，在线语音合成功能可能无法使用；
  • 关闭震动提醒后，提醒触发时可能不再震动。

六、我们如何保存信息

1. 保存地点

本应用产生的学习内容、学习计划、提醒设置、复习记录等信息，默认保存在您的设备本地。

我们在中华人民共和国境内收集和产生的个人信息，将依法存储在中国境内。若后续涉及向境外提供个人信息，我们将依法履行相应程序，并取得您的单独同意。

2. 保存期限

本地学习数据、学习计划、提醒设置等信息会保存至以下任一情形发生：

  • 您在应用内主动删除相关内容；

  • 您通过系统设置清除应用数据；

3. 删除方式

方式一：在应用内清理本地数据

欧创易 → 设置 → 清除本地数据

通过该功能，您可以清理本应用产生的本地缓存数据、学习相关本地数据或其他本地保存的信息。清理后，相关本地数据可能无法恢复，请谨慎操作。

方式二：通过系统设置清除全部应用数据

Android 系统设置 → 应用管理 → 欧创易 → 存储 → 清除数据

通过系统设置清除数据后，本应用保存在设备本地的学习记录、学习计划、提醒设置、应用配置等信息可能会被删除且无法恢复，请谨慎操作。
