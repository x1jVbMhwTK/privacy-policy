武汉市用和邦科技有限公司（以下简称“我们”）重视您的个人信息和隐私保护。本隐私政策适用于我们提供的“万象信”安卓应用（以下简称“本应用”），用于说明您使用本应用时，相关信息的处理方式，以及您如何管理自己的数据。

万象信是一款以本地使用为核心的笔记、待办与物品档案管理工具。当前版本不提供账号注册、登录或云同步服务，未声明应用联网权限，未接入广告、统计分析或在线服务类第三方 SDK，不将您的记录上传至我们的服务器。

请在使用本应用前阅读本政策，尤其是与本地存储、文件导出、数据删除和第三方服务有关的内容。

01

我们如何处理您的信息

1. 您主动输入的记录

当您使用相应功能时，本应用会在您的设备本地处理和保存您主动输入的信息，包括：

  • 笔记信息：标题、正文、分类、标签、卡片颜色和置顶状态。
  • 待办信息：任务标题、详细说明、分类、标签、优先级、截止日期、完成状态和置顶状态。
  • 物品档案信息：物品名称、说明、分类、标签、存放位置、购买价格、购买日期和保修截止日期。
  • 记录管理信息：记录标识、创建时间、更新时间及回收站状态。
  • 应用设置：您选择的跟随系统、浅色或深色主题设置。

以上信息用于实现记录保存、编辑、搜索、分类筛选、置顶、任务管理、日期提示、统计展示、回收站和备份恢复等功能。

您的记录保存在本地

这些信息保存在本应用的内部本地存储中，不通过本应用上传给我们。我们不会因为您使用这些本地功能而在服务器端收集您的记录。

您可以自行决定记录内容。请谨慎填写身份证号码、银行账号、密码、医疗信息等敏感内容，并避免在没有合法依据的情况下记录他人的个人信息。

2. 自动生成的本地信息

为区分记录、确定展示顺序及处理备份合并，本应用会在本地生成记录标识、创建时间和更新时间。

记录标识用于区分本应用内的记录，不用于识别您的设备，也不用于跨应用跟踪。

3. 我们不主动收集的信息

当前版本不通过本应用主动收集您的手机号、账号信息、通讯录、短信、通话记录、位置、设备广告标识或设备唯一标识，也不通过广告或统计 SDK 收集您的使用行为。

当前版本不提供后台通知提醒。任务截止日期和保修日期提示在应用内展示。

4. 您主动联系我们时提供的信息

当您通过电子邮箱联系我们时，我们会处理您的邮箱地址、邮件内容，以及您主动提供的附件或其他信息，用于沟通、排查问题、答复咨询或处理您的请求。

请尽量不要在邮件中发送与问题无关的敏感信息。如果需要提供截图或备份文件，请先删除或遮盖不必要的个人信息。

此类邮件通信独立于本应用的本地记录功能。我们只在处理相关事项及满足必要法律义务所需的范围内保留相关信息，不将其用于广告营销。

02

应用权限与系统功能

1. 应用权限

不申请非必要敏感权限

当前版本< strong>未声明联网权限，也不申请通讯录、短信、电话、定位、相机、麦克风、通知或全盘存储访问权限。

2. 系统文件选择器

当您主动导入备份或导出文件时，本应用调用 Android 系统文件选择器，访问您明确选择的文件或目标保存位置，不扫描您的全部设备文件。

文件访问授权范围及有效期由 Android 系统和您选择的文档提供程序管理。

3. 系统分享

当您主动点击分享，并选择目标应用时，本应用将所选记录的标题和正文交给您选择的目标应用。

分享后，目标应用如何处理这些内容，由其自身的隐私政策和服务规则约束。请在分享前确认记录内容和接收对象。

03

备份、导入与导出

1. JSON 备份

您可以主动导出 JSON 备份。备份包含本应用中的记录、回收站记录及主题设置，用于日后恢复数据。

导入备份时，本应用在本地读取和校验您选择的文件，并允许您预览后选择合并恢复或替换当前数据。合并时，同一记录标识的记录以更新时间较新的内容为准。

替换恢复会覆盖当前数据。请在操作前确认备份内容，并根据需要备份现有记录。

2. CSV 导出

您可以主动将未在回收站中的记录导出为 CSV 文件，用于在表格软件中查看。CSV 不用于本应用的数据恢复。

3. 导出文件的安全

备份文件未加密

当前版本导出的 JSON 和 CSV 文件未加密，可能包含您输入的个人信息或其他私密内容。请将文件保存在可信位置，并谨慎转发。

本应用内删除记录或卸载应用，不会自动删除您已经导出的文件。您需要自行管理和删除这些文件。

4. 云盘及其他文件提供程序

如果您通过系统文件选择器将文件保存到云盘，或从云盘导入文件，相关云端存储、同步和传输行为由您选择的文件提供程序实施，不属于本应用提供的云同步服务。

请阅读相应服务提供方的隐私政策，并确认其适合保存您的记录。

04

信息的存储与保留

1. 本地记录

本应用记录及设置保存在当前设备的应用内部本地存储中。当前版本不设置用于保存这些记录的开发者服务器。

本地记录通常保留至您主动删除、替换数据、清除应用数据或卸载应用时。进入回收站的记录仍然保存在本地，直至您恢复、永久删除或清空回收站。

2. 系统备份

当前版本在应用配置中关闭系统自动备份，并配置排除应用数据的系统备份与设备迁移规则。

不同设备厂商的系统工具或您自行使用的备份工具可能具有不同的处理方式，请同时了解相关工具的说明。

3. 邮件咨询信息

您通过邮件主动提供的信息，会在处理相关事项、后续必要沟通及满足适用法律义务所需的期限内保留。我们会对不再需要的信息采取适当的删除或其他处置措施。

05

共享、转让与公开披露

当前版本不会主动将您保存在本应用中的记录共享、转让或公开披露给第三方，也不会出售您的个人信息。

以下由您主动发起的行为不属于我们在后台共享记录：

  • 通过系统分享将记录发送给您选择的应用或接收方；
  • 将备份或导出文件保存到您选择的云盘或其他存储服务；
  • 通过邮件主动向我们发送问题说明、截图或文件。

对于我们因邮件咨询等方式实际持有的信息，如依法需要提供，我们将依照适用法律规定处理，并在法律允许的范围内采取必要措施。

06

第三方组件与服务

当前版本使用 Android、AndroidX、Jetpack Compose、Material 3 及 Kotlin 相关基础组件，实现界面展示、本地数据处理和系统功能调用，未接入用于广告投放、行为统计或记录上传的第三方 SDK。

您选择使用的分享目标应用、文件提供程序、邮箱服务及设备操作系统可能按照各自的规则处理信息。此类独立服务的处理行为不由本政策替代。

隐私政策网页的访问

本政策适用于万象信应用。如果您通过网页查看本政策，网页托管服务可能产生为提供网页服务所需的访问日志；该处理行为应按实际网页部署情况另行说明，不应被理解为万象信应用上传了您的记录。

07

我们如何保护信息

我们通过应用内部存储、减少权限申请、不接入非必要在线服务以及本地文件原子写入等措施，降低不必要的数据访问和文件写入异常风险。

安全措施的限制

上述措施不代表数据已加密，也不能保证在设备丢失、被恶意软件控制、系统遭破解、存储损坏或操作失误等情况下数据绝对安全。

当前版本不提供应用内密码锁或备份文件加密功能。

建议您：

  • 为设备设置可靠的锁屏密码，并保持系统更新；
  • 不将私密备份保存到不可信位置；
  • 定期导出并妥善保存 JSON 备份；
  • 在分享、导出及发送问题附件前检查其中是否包含敏感信息。
08

您如何管理自己的信息

1. 查看、更正和导出

您可以直接在本应用中查看、搜索、编辑记录，通过 JSON 备份或 CSV 导出获取相应数据副本。

2. 删除和恢复

您可以将记录移入回收站，并在回收站中恢复或永久删除记录。也可以清空回收站，或在设置页面删除全部记录。

“永久删除”表示相应记录从本应用当前使用的数据文件中移除，并不构成对设备存储介质进行取证级不可恢复擦除的承诺。

您已导出的文件，以及此前发送至其他应用或接收方的内容，不会随本应用内删除操作自动删除。

3. 停止使用

卸载前请先备份

您可以停止使用、清除应用数据或卸载本应用。卸载或清除应用数据通常会删除本应用的本地数据，建议提前备份。

当前版本没有账号系统，因此不涉及账号注销。

4. 联系我们处理请求

如您对我们因邮件联系等方式实际持有的个人信息提出查阅、更正、删除或其他合法请求，可通过 whyhbkj@163.com 联系我们。

我们可能在必要范围内核实请求与您的关联，以避免他人冒用身份。在核实后，我们会在适用法律要求的期限内处理并答复。

对于仅保存在您设备上的记录，我们无法远程读取、修改、删除或恢复，请通过本应用的相应功能操作。

09

未成年人保护

如果您是未成年人，建议在父母或其他监护人的指导下阅读本政策并使用本应用，谨慎记录、分享或导出个人信息。

如果您不满十四周岁，应在取得父母或其他监护人同意后使用本应用。当前版本不提供用户身份识别或年龄验证功能，也不会通过服务器主动收集儿童的本地记录。

如果监护人发现未成年人通过邮件向我们提供了不应提供的个人信息，或对相关信息处理有疑问，请通过本政策所列邮箱联系我们。

10

隐私政策的更新

如本应用功能、数据处理方式或适用法律要求发生变化，我们会相应更新本政策，并通过应用内说明、政策页面或其他适当方式告知您。

如果未来增加账号、云同步、广告、统计分析、在线服务或新的权限申请，我们将在相关功能启用前说明新增处理目的、信息类型及相关规则，并依法取得必要的同意或授权。

本政策更新不会当然授权我们对已存在的信息进行与原处理目的不相符的处理。
